# Política de publicación de la Megabase V4

**No existe autorización docente ni del IMEF para difundir institucionalmente este catálogo.** El ZIP es una preparación técnica.

- GitHub Pages y los archivos estáticos accesibles por URL son públicos.
- No insertar información empresarial confidencial, datos personales ni archivos originales internos en el repositorio.
- `06_PROPUESTAS_AUTORIZADAS_DIFUSION.csv` permanece con cero registros.
- Las 249 fichas expresan hipótesis preliminares, no hechos demostrados.
- Las 189 familias recuperadas del histórico requieren revisión semántica individual.
- Las 116 candidatas causales siguen no habilitadas.
- Confirmar con el profesor qué campos, propuestas, fichas y fuentes podrán publicarse, y revisar el listado final antes del despliegue.
